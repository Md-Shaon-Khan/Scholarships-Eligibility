# Scholarship Finder AI

AI-powered scholarship discovery, eligibility analysis,
CV evaluation, and personalised scholarship matching platform.

## Features

- Scholarship aggregation
- Weighted scholarship ranking
- Search and filtering
- Scholarship details
- Student profile management
- CV analysis
- Eligibility checking
- Gap analysis
- Personalised scholarship matching
- Application tracking
- Deadline monitoring
